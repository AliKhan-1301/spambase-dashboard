How the data was cleaned

    Read this before trusting the model

    • The real mail comes from one mailbox. The dataset's own documentation says the non-spam emails were collected at HP Labs, so "george", "hp", "650" (the local area code) and "1999" are among the strongest real-mail signals. The model has partly learned whose inbox this is, and would need retraining on any other mailbox.
    • Frequencies, not words. Each feature is the percentage of words (or characters) in an email that match, so word order and meaning are lost.
    • Spam in 1999 looked different. Use the findings as a method and a baseline, not as a description of today's spam.
    Data: Hopkins, Reeber, Forman and Suermondt, Spambase, UCI Machine Learning Repository (1999).
